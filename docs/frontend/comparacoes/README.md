# Comparações das telas web com o protótipo (B4)

Cada imagem mostra a última rodada de comparação da tela: o protótipo (`design/`) à esquerda e a implementação à direita. Reduzidas para JPEG; as rodadas intermediárias não foram guardadas.

Diferenças que ficaram, todas justificadas por uma decisão:
- **P8:** sem as linhas e faixas de Aula e Estágio no Hoje, no calendário e no onboarding.
- **P14:** o check-in fica em 2×2 por causa do quarto chip, Elétrico.
- **P18:** gamificação com valores fixos. Na W41 os contadores ficam em 6 / 340 / Nv 7 e o fundo não é reencaixado, porque os dados de exemplo não calculam plano.
- **P20:** a W30 começa vazia, sem os elementos da IA. O campo de data é o nativo do navegador.
- **Contrato:** os objetivos usam o título completo (o contrato não tem nome curto) e "Entrega dd/mm" no lugar de Prova/Publicar.
- **UC13:** sem tarefas leves, que estão fora do contrato.
- O "N" no canto inferior das capturas é o indicador de desenvolvimento do Next.
